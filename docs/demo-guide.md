# 시연 가이드

## 목적지 → 추천 → 기본 내비

1. Pleos Connect 2.1.0 에뮬레이터를 정차 상태로 실행합니다. 기본 내비 지도와 장소 검색을 위한 네트워크가 필요합니다.
2. ParkFlow 실행 → `내비로 시작하기` → 알림 권한 허용. QR 스캔이나 모바일 계정은 필요하지 않습니다.
3. 기본 내비에서 삼성역 인근 카페머머를 검색해 목적지로 설정합니다. 검색 데이터가 달라지면 삼성역 인근의 다른 장소도 사용할 수 있습니다. 특정 카페의 현재 영업 여부·전용 주차장 유무를 보장하는 시나리오는 아닙니다.
4. 추천 알림의 `다른 주차장 보기`를 누르면 최대 3곳의 주차장 비교 화면이 열립니다. 2시간을 선택하면 영동대로96길 주차장의 과거자료 기반 추정 요금은 7,200원입니다. 직선거리는 도보 시간이 아닙니다.
5. `이곳으로 안내`를 누르면 기본 내비로 전환되고 선택한 주차장으로 경로를 요청합니다. 앱은 목적지 재조회 좌표가 선택 지점 25m 이내인지 확인합니다.
6. 추천 알림의 `이곳으로 안내`를 직접 누르는 경로도 지원합니다. 새 목적지 설정, 체류 시간 변경, 120초 경과 등으로 만료된 알림은 경로를 바꾸지 않습니다.

## P 전환 후 차량 내 기록 (모바일 기능과 별개)

1. [공식 버추얼 콘솔 가이드](https://document.pleos.ai/en/docs/connect/guide/getting-started/application-development/use-vehicle-emulator)에 따라 `adb forward tcp:8088 tcp:8088`을 실행하고 PC 브라우저에서 `http://127.0.0.1:8088/`을 엽니다. 여러 기기가 있으면 `adb -s SERIAL forward tcp:8088 tcp:8088`을 사용합니다. 주차장 경로가 승인된 뒤 콘솔의 N을 누르고 P로 변경합니다. 초기 P 상태나 반복 P 입력은 새 주차로 판단하지 않습니다.
2. `주차 기록 남기기` 알림에서 `기록 남기기`를 누르면 주차 확인 화면이 열립니다. `나중에`는 이번 제안을 닫습니다.
3. `주차 확인하고 기록하기`를 눌러야 기록이 저장됩니다. 기어 P만으로 도착·실제 주차를 확정하거나 자동 저장하지 않습니다.
4. 차량 화면의 위치 메모와 기록 조회는 차량 단독 PoC 기능입니다. 최종 영상의 휴대폰 사진 기록·복귀 확인은 별도 목표 UX입니다.
5. 기록 후 앱을 다시 실행하면 저장된 차량 내 기록이 복원됩니다. 자동 서버 업로드나 휴대폰 동기화는 없습니다.

## 문제가 생겼을 때

- **팝업이 보이지 않음:** 앱 알림 권한/채널, 서비스 시작 여부, 내비 목적지 설정 여부를 확인합니다. 알림함과 ParkFlow 비교 화면도 확인하세요. `notify()` 성공 로그만으로 팝업이 보였다고 판단하지 않습니다.
- **주차장 후보가 없음:** 자료 범위는 강남구의 일부 50곳입니다. 목적지 직선 1km 이내 후보만 제시합니다.
- **연결 실패:** 기본 내비 서비스가 포함된 공식 Pleos 이미지인지 확인한 뒤 앱의 재시도 또는 주차 준비 재시작을 사용합니다.
- **P 이벤트 미지원:** 앱에서 `주차했어요`로 직접 확인할 수 있습니다.
- **INSTALL_FAILED_UPDATE_INCOMPATIBLE:** 서명이 다른 기존 앱이 있습니다. 기존 기록을 보존하고 새 테스트 환경에 설치합니다.

모든 화면 조작은 정차 중 진행합니다. 사용 후 설정의 `주차 준비 중지`로 이벤트 수신을 중단할 수 있습니다.
